Configuration du module Bluetooth

Pour connecter votre altimètre à votre téléphone ou tablette via Bluetooth, le module doit impérativement être configuré à la même vitesse de communication que votre carte altimètre.

Cet écran vous permet de programmer des modules standards compatibles tels que les HC-05, HC-06, JDY-30, JDY-31, SPP et AT-09.

Matériel requis

  • Câble adaptateur USB-Série TTL
  • Adaptateur USB OTG (USB-C ou Micro-USB selon votre appareil Android)
  • Adaptateur JST et cordons de liaison JST correspondants

Ces modules sont généralement livrés préconfigurés à 9600 bauds. Cependant, votre altimètre fonctionne par défaut à 38400 bauds. Vous devez donc vous assurer de programmer la vitesse adéquate.

ATTENTION : Ne débranchez jamais le module ou le câble pendant la lecture ou l'écriture des paramètres.

Charger la configuration du module

  1. Raccordez le module Bluetooth à votre appareil Android à l'aide du câble TTL et de l'adaptateur USB OTG.
  2. Sélectionnez le modèle de module dans le menu déroulant. Si vous ne le connaissez pas, choisissez HC-05, HC-06 ou Unknown. Si aucun profil ne fonctionne, envoyez-moi les références et des photos de votre module.
  3. Appuyez sur [Charger cfg]. L'application essaiera de se connecter à la vitesse par défaut de 38400 bauds. En cas d'échec, elle testera différentes vitesses jusqu'à établir la liaison.
  4. Une fois connecté, la configuration actuelle du module est chargée afin que vous puissiez la modifier.

Sauvegarder la nouvelle configuration

  1. Modifiez les paramètres désirés (nom du module, code PIN, vitesse). Assurez-vous de choisir une vitesse compatible avec votre carte altimètre (en général 38400 bauds).
  2. Appuyez sur [Sauver cfg]. Les commandes sont écrites dans le module. Si une erreur survient pendant la sauvegarde, celle-ci est interrompue en toute sécurité.

Remarque : Vous devez répéter ces mêmes étapes individuellement pour chaque module Bluetooth à configurer.
