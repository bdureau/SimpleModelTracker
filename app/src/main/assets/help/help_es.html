Ayuda de Simple Model Tracker

Esta aplicación se puede utilizar con un módulo GPS conectado a un módulo de telemetría de largo alcance como Ebyte LoRa o 3DR.

Le permite rastrear cualquier modelo mostrando la última posición conocida directamente en el mapa.

Es posible conectarse al receptor de telemetría mediante un cable USB (OTG) o a través de un módulo Bluetooth.
