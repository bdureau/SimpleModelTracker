Configuración del módulo Bluetooth

Para conectar su altímetro a su teléfono o tableta mediante Bluetooth, primero deberá configurarlo para que funcione a la misma velocidad de comunicación que la placa del altímetro.

Esta pantalla le ayudará a configurar módulos compatibles como HC-05, HC-06, JDY-30, JDY-31, SPP y AT-09.

Material necesario

  • Cable adaptador USB a serie TTL
  • Adaptador USB OTG (USB-C o Micro-USB según su dispositivo Android)
  • Adaptador JST y cables de conexión JST compatibles

Tenga en cuenta que estos módulos suelen venir preconfigurados de fábrica a 9600 baudios. Sin embargo, su placa del altímetro funcionará por defecto a 38400 baudios, por lo que debe asegurarse de conectarse a la velocidad correcta.

ATENCIÓN: Asegúrese de no desconectar el módulo ni el cable durante las operaciones de lectura o escritura.

Recuperar la configuración del módulo

  1. Conecte el módulo a su dispositivo Android utilizando el cable TTL y el adaptador USB OTG.
  2. Seleccione el modelo de módulo Bluetooth en el menú desplegable. Si no está seguro, elija HC-05, HC-06 o Unknown. Si ningún módulo responde, envíeme las referencias y fotos del módulo.
  3. Pulse en [Recuperar cfg]. La aplicación intentará conectarse utilizando la velocidad predeterminada de 38400 baudios. Si falla, probará varias velocidades de transmisión hasta conectarse.
  4. Una vez establecida la conexión, se recuperará la configuración del módulo para que pueda modificarla.

Guardar la nueva configuración

  1. Cambie los ajustes que desee, como el nombre del módulo, PIN o velocidad. Asegúrese de seleccionar una velocidad compatible con su placa (habitualmente 38400 baudios).
  2. Pulse en [Guardar cfg]. Esto guardará la configuración en el módulo. Si ocurre algún error durante el guardado, el proceso se cancelará de forma segura.

Nota: Deberá repetir este mismo procedimiento de forma individual para cada módulo Bluetooth que desee configurar.
