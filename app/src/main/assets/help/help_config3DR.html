3DR Telemetry Module Configuration

To enable long-range telemetry, replace the standard Bluetooth module with a 3DR radio telemetry module.

Ensure your Android device battery can supply adequate power to the 3DR radio. If using a high-power transceiver, connect an external power supply or powered USB hub.

Required Hardware

  • USB-to-TTL serial cable
  • USB OTG adapter (USB-C or Micro-USB depending on your device)
  • JST adapter board and matching JST connection wiring

Factory default modules usually operate at 57600 baud. However, the altimeter or GPS board runs at 38400 baud by default. Ensure your communication parameters match.

3DR radio systems operate in pairs: you must configure both the onboard airborne transmitter and the ground receiver with identical settings (Net ID, frequency, channels, and baud rate).

CAUTION: Never disconnect the module or cable while read or write operations are in progress.

Retrieving the Module Configuration

  1. Connect the 3DR module to your Android device using the USB OTG adapter and TTL serial cable.
  2. Tap [Retrieve cfg]. The application will scan through multiple standard baud rates until communication is established.
  3. Once synchronized, the current module parameters will load into the form.

Saving the Module Configuration

  1. Adjust the settings as required (baud rate, Net ID, frequency band, air speed, power level). Ensure the baud rate matches your altimeter board.
  2. Tap [Save cfg]. The AT parameters will be written and saved to non-volatile memory (EEPROM). If an error occurs, the process halts safely.

Note: Repeat this configuration procedure for both modules of your 3DR transceiver pair.
