Bluetooth Module Configuration

In order to configure your Bluetooth module to connect your altimeter to your phone or tablet, it must operate at the same communication baud rate as the altimeter board.

This configuration utility enables you to configure compatible modules such as HC-05, HC-06, JDY-30, JDY-31, SPP, and AT-09.

Required Hardware

  • USB-to-TTL serial cable
  • USB OTG adapter (USB-C or Micro-USB depending on your Android device)
  • JST adapter board and matching JST connection wiring

Most commercial modules arrive pre-set to 9600 baud. However, your altimeter flight board runs at 38400 baud by default. Ensure your communication parameters match.

CAUTION: Do not disconnect the module or cable while read or write operations are in progress.

Retrieving the Module Configuration

  1. Connect the Bluetooth module to your Android device using the TTL cable and USB OTG adapter.
  2. Select your module type from the dropdown list. If uncertain, choose HC-05, HC-06, or Unknown. If no profile works, contact support with clear pictures and references of your module.
  3. Tap [Retrieve cfg]. The app will attempt to connect using the default 38400 baud rate. If connection fails, it will automatically cycle through various baud rates until synchronization is achieved.
  4. Once connected, the current module parameters will load automatically into the form.

Saving the Module Configuration

  1. Adjust the settings as required (module name, PIN, and baud rate). Ensure the selected baud rate matches your altimeter board (typically 38400 baud).
  2. Tap [Save cfg]. The configuration commands will be written to the module. If any error occurs, the saving process will abort safely.

Note: Repeat this configuration procedure individually for each Bluetooth module you wish to configure.
