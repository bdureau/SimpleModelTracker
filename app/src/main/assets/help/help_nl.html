Help Simple Model Tracker

Deze applicatie kan worden gebruikt met een GPS-module die is aangesloten op een telemetriemodule voor lange afstand, zoals Ebyte LoRa of 3DR.

Hiermee kunt u elk model volgen door de laatst bekende positie direct op de kaart weer te geven.

Verbinding met uw telemetriemodule voor lange afstand is mogelijk via een USB-kabel (OTG) of een Bluetooth-module.
