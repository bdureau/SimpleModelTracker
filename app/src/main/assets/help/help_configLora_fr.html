Configuration du module eByte LoRa E220

Pour effectuer de la télémétrie longue distance, remplacez votre module Bluetooth par un module radio longue portée de la série eByte LoRa E220.

Modules testés et supportés

  • E220-400T30D
  • E220-400T30S
  • E220-900T30D
  • E220-900T30S
  • E220-400T22D
  • E220-900T22S

Matériel requis

  • Câble adaptateur USB-Série TTL
  • Adaptateur USB OTG (USB-C ou Micro-USB selon votre appareil Android)
  • Adaptateur JST et câbles de liaison JST correspondants

La batterie de votre appareil Android doit fournir une alimentation suffisante au module LoRa. Pour les modules émettant à forte puissance (30 dBm / 1W), prévoyez une batterie externe.

Mode Configuration (M0/M1) : Placez les 2 cavaliers sur les broches M0 et M1 pour basculer le module en mode programmation.

Vitesse de programmation : La lecture et l'écriture des registres de configuration s'effectuent toujours à 9600 bauds. La vitesse de transmission des données en vol doit correspondre à celle de l'altimètre (38400 bauds par défaut).

Les modules LoRa fonctionnent par paire : vous devez programmer l'émetteur embarqué et le récepteur au sol avec les mêmes paramètres (canal, adresse, débit radio et clé de chiffrement).

ATTENTION : Ne débranchez jamais le module ou le câble pendant la lecture ou l'écriture des paramètres.

Charger la configuration du module

  1. Vérifiez que les deux cavaliers sont en place, puis raccordez le module à votre appareil Android avec le câble TTL et l'adaptateur USB OTG.
  2. Appuyez sur [Charger cfg]. L'application se connecte à 9600 bauds et lit les registres du module.
  3. Une fois la lecture terminée, les paramètres actuels s'affichent automatiquement à l'écran.

Sauvegarder la nouvelle configuration

  1. Modifiez les paramètres souhaités. Assurez-vous que la vitesse série choisie correspond bien à votre altimètre (38400 bauds par défaut).
  2. Vérifiez que les canaux de fréquence et la clé de chiffrement sont parfaitement identiques sur l'émetteur et le récepteur.
  3. Appuyez sur [Sauver cfg]. Les paramètres sont enregistrés en mémoire non volatile. En cas d'erreur, l'écriture est interrompue.

Remarque : Cette opération de configuration doit être répétée individuellement sur chacun des deux modules.

Important : Retirez impérativement les deux cavaliers (mode normal M0=0, M1=0) avant de procéder aux vols.

Note de compatibilité : Les modules de télémétrie LoRa ne sont pas compatibles actuellement avec les cartes altimètres à base d'ESP32.
