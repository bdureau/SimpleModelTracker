Simple Model Tracker Configuration

The appearance, display units, and operational behavior of the application can be customized across two configuration screens.

First Screen: General Settings

  • Trajectory line color: Choose the color of the tracking path rendered on the map.
  • Help language: Force the application help documentation language. English is the reference language and will always be up to date.
  • Application units: Toggle between Metric (meters, km/h) and Imperial (feet, mph) measurement units.
  • Baud rate: Adjust the serial communication speed if using slower telemetry transceiver modules.
  • Connection type: Select between Bluetooth or USB OTG connection. Bluetooth is recommended if your physical USB cable tends to be loose.
  • Model type: Select custom map marker icons matching the specific type of model aircraft or rocket you are tracking.

Second Screen: Voice Telemetry

Configure audio speech synthesis for telemetry callouts. While keeping your eyes on the sky to spot your model, audio alerts allow you to monitor flight events hands-free. You can customize which flight events are spoken as well as the voice profile.
