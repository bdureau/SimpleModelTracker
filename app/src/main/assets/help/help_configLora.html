Ebyte LoRa E220 Module Configuration

To enable long-range telemetry, replace the standard Bluetooth module with an Ebyte LoRa E220 telemetry module.

Supported & Tested Modules

  • E220-400T30D
  • E220-400T30S
  • E220-900T30D
  • E220-900T30S
  • E220-400T22D
  • E220-900T22S

Required Hardware

  • USB-to-TTL serial cable
  • USB OTG adapter (USB-C or Micro-USB depending on your Android device)
  • JST adapter board and matching JST connection wiring

Ensure your Android device battery can supply adequate power to the LoRa module. If using a high-power module (e.g. 30 dBm / 1W), connect an external power source.

Configuration Mode (M0/M1): Place both jumpers on M0 and M1 (or pull both pins HIGH) to enter configuration mode.

Module Configuration Port: The module's internal configuration registers operate strictly at 9600 baud. The application baud rate for flight data must match the altimeter board (typically 38400 baud).

LoRa systems operate in pairs: configure both the airborne transmitter and ground receiver with matching RF parameters (channel, address, air data rate, and encryption key).

CAUTION: Never disconnect the module or cable while read or write operations are in progress.

Retrieving the Module Configuration

  1. Ensure both configuration jumpers are installed, then connect the module to your Android device via the TTL cable and USB OTG adapter.
  2. Tap [Retrieve cfg]. The app connects at 9600 baud and reads all internal registers.
  3. Once retrieved, the current settings load into the configuration form.

Saving the Module Configuration

  1. Adjust the settings as required. Ensure the serial baud rate matches your altimeter board (38400 baud by default).
  2. Verify that frequency channels and encryption keys match identically on both the transmitter and receiver.
  3. Tap [Save cfg]. Configuration registers are written permanently. If an error occurs, the process halts safely.

Note: Repeat this configuration procedure individually for both modules of the pair.

Crucial: Remove both jumpers (set M0 and M1 to LOW / normal mode) before flight operations.

Compatibility note: LoRa telemetry modules are currently not supported on ESP32 altimeter boards.
