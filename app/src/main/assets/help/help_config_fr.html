Configuration de Simple Model Tracker

L'apparence visuelle, les unités et le comportement de l'application se configurent facilement via deux écrans dédiés.

Premier écran : Paramètres généraux

  • Couleur du tracé : Choisissez la couleur de la ligne de suivi affichée sur la carte.
  • Langue de l'aide : Sélectionnez la langue des fichiers d'aide. L'anglais étant la langue principale de développement, elle reste toujours à jour.
  • Unités de l'application : Basculez entre le système métrique (mètres, km/h) et le système impérial (pieds, mph).
  • Vitesse en bauds (Baud rate) : Modifiez la vitesse de communication série si vous utilisez un module de télémétrie plus lent.
  • Type de connexion : Choisissez entre une liaison Bluetooth ou USB OTG. Le Bluetooth offre une meilleure fiabilité si votre connecteur USB a du jeu.
  • Type de modèle : Personnalisez l'icône du marqueur sur la carte en fonction du type de modèle ou de fusée suivi.

Deuxième écran : Télémétrie vocale

Configurez la synthèse vocale pour les annonces de télémétrie en temps réel. Lorsque vous suivez visuellement votre modèle des yeux, les alertes sonores vous permettent de rester informé sans regarder l'écran. Vous pouvez choisir les événements à annoncer et sélectionner la voix souhaitée.
